## 👨‍💻 Sobre mim

Sou desenvolvedor Full Stack e atuo na construção de aplicações completas, desde a interface utilizada pelo usuário até a arquitetura, APIs, banco de dados, infraestrutura e publicação em produção.

No **front-end**, desenvolvo dashboards, portais e sistemas empresariais responsivos, buscando criar interfaces organizadas, intuitivas e capazes de apresentar grandes volumes de informações de maneira simples.

No **back-end**, trabalho com APIs, autenticação, integrações, bancos de dados, processamento de informações e arquiteturas para aplicações empresariais.

Também desenvolvo soluções baseadas em Inteligência Artificial. Entre elas, criei para a empresa em que trabalho um sistema de **orquestração de IA multiagente**, no qual diferentes agentes especializados trabalham de maneira coordenada para analisar informações, executar tarefas e automatizar processos internos.

Atualmente, meus principais focos são:

* Sistemas empresariais e plataformas SaaS
* Dashboards e interfaces para análise de dados
* Desenvolvimento front-end com React e Next.js
* APIs e arquiteturas back-end com Node.js, NestJS e Python
* Automação de processos internos
* Integração de modelos de linguagem
* Orquestração de sistemas multiagente
* Infraestrutura em nuvem e otimização de custos
